Contoh 2750. Digit paling kiri = bit spesial (boleh kosong). Tiga sisanya menjawab: apa yang boleh owner, anggota group, dan other (semua orang lain).

Jumlahkan saklar yang menyala → satu angka 0–7. Tiap angka = tepat satu pola.

--x: capai file jika tahu namanya, tak bisa ls. r--: lihat daftar tapi tak bisa masuk/buka.

Digit keempat: bit spesial

bitnilaihuruf di lspada filepada direktori
setuid4s (x owner)jalan sebagai owner file (passwd→root)diabaikan
setgid2s (x group)jalan sebagai group filefile baru warisi group direktori
sticky1t (x other)diabaikanhanya pemilik file boleh hapus (/tmp)

Huruf besar S/T = bit nyala tapi x mati (sering salah konfigurasi). setuid-root pada file writable = jalan ke root.

Membaca ls -l

d rwx r-x r-- ^ ^^^ ^^^ ^^^ │ │ │ other │ │ group │ owner tipe: - file · d dir · l link

Bit spesial menggeser huruf x: s owner/group, t other.

Mode yang sering dipakai

600rw-------privat (kunci SSH)
640rw-r-----secret, group boleh baca (.env)
644rw-r--r--file publik-baca (default)
700rwx------dir/skrip privat
750rwxr-x---dir: owner penuh, group masuk
755rwxr-xr-xdir/exec publik masuk+baca
775rwxrwxr-xgroup bisa tulis (berisiko)
2750rwxr-s---dir setgid: anak warisi group
1777rwxrwxrwtdir sticky world-write (/tmp)
4755rwsr-xr-xexec setuid: jalan sbg owner

Cara mengecek

stat -c '%a %A %U %G %n' PATH # oktal + simbolik + owner + group
namei -l /a/b/c.env # izin TIAP komponen path — temukan tembok traverse
id USER ; groups USER # user anggota group apa (penentu akses "group")
sudo -u www-data cat PATH # bukti akses nyata, bukan terkaan
sudo find / -perm -4000 -type f 2>/dev/null # semua setuid (-2000 setgid, -1000 sticky)
find DIR -perm -0002 -type f # file world-writable
grep -R -n ' root ' /etc/cron.d/ # cron yang jalan sebagai root

Least privilege: matikan tiap saklar yang tidak wajib menyala. Satu bit keliru menyala = satu celah.
